# Lila eyes

The `wk-esp32s3-dev` build shows Lila's face as 21 animated 240x240 GIFs, one
per emotion the server can send. This directory is the collection: the build
packs it through the `lila-gif` emoji collection selected in
`main/CMakeLists.txt`.

## Design

- Two big eyes with a violet iris, a lilac ring and a deep-violet pupil.
- Four long curved lashes on the outer corner of each eye, drawn on the open
  lid or on the closed lid when Lila blinks.
- A tapered eyeliner that ends in a small wing at the outer corner.
- Seven colours only: black background, white sclera, lilac, violet, deep
  violet, pink for the blush and hearts, tear blue for the drops.
- 26 to 40 frames per loop at 100 ms per frame, so each loop lasts 3 to 4 s.
- 240x240 pixels, the panel resolution of the `wk-esp32s3-dev` build.

The small palette and the taut loops are deliberate: the whole collection is
about 258 KiB, which fits in the 4 MB assets partition next to the 16 px
common font.

## Regenerating

The GIFs are generated by `generate_eyes.py` with
[Pillow](https://python-pillow.org/):

```sh
python -m pip install pillow
python main/assets/emoji/lila-gif/generate_eyes.py
```

The script writes one GIF per emotion into this directory. Pass `--out DIR` to
write them somewhere else, for example to preview a design change without
touching the build assets.

The generator is a design tool: it is not compiled, not packed and not part of
the firmware. Edit the drawing helpers (`open_eye`, `closed_eye`, `lashes`,
`liner`, `blush`) to change the look, then regenerate and inspect a few frames
before committing.
